# Bento Dashboard ประเด็นท้าทาย ว.PA 2568 📊

ระบบแดชบอร์ดสรุปผลการพัฒนางานตามข้อตกลง (ว.PA) ประจำปีงบประมาณ 2568  
**ครูณรงค์ฤทธิ์ อ่อนน่วมน้อย** • โรงเรียนสุโขทัยวิทยาคม • สพม.สุโขทัย

---

## 📱 วิธีติดตั้งเป็นแอปบนไอแพด (iPad / iPhone)

ระบบนี้รองรับ **Progressive Web App (PWA)** เต็มรูปแบบ สามารถติดตั้งไว้บนหน้าจอโฮมของไอแพดเพื่อเปิดใช้งานแบบเต็มหน้าจอ (Standalone Fullscreen) เหมือนแอปพลิเคชันจาก App Store:

1. เปิดเบราว์เซอร์ **Safari** บนไอแพด
2. เข้าลิงก์: **[https://lamica97.github.io/pa-challenge-dashboard/](https://lamica97.github.io/pa-challenge-dashboard/)**
3. แตะที่ปุ่ม **แชร์ (Share)** ⎋ (ไอคอนสี่เหลี่ยมที่มีลูกศรชี้ขึ้น บริเวณแถบด้านบนของ Safari)
4. เลื่อนลงมาแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)** ➕
5. ตั้งชื่อแอป (ค่าเริ่มต้น: `ว.PA 2568`) แล้วแตะ **"เพิ่ม" (Add)**
6. ไอคอนตราโรงเรียนสุโขทัยวิทยาคมจะปรากฏบนหน้าจอโฮมของไอแพดทันที แตะเปิดใช้งานแบบแอปได้ทันทีโดยไม่มีแถบเบราว์เซอร์มากวนใจ!

## 🎯 โครงสร้างเนื้อหาประเด็นท้าทาย (6 ส่วน)
1. **ผลสัมฤทธิ์ปลายทาง (Key Result):** ร้อยละ 72.50% (58 คน) ผ่านเกณฑ์เป้าหมาย PA (+12.50%)
2. **สภาพปัญหาตั้งต้น (SAR ปี 2567):** ผลการประเมินเดิม 45.00% ต่ำกว่าเป้าหมาย 50%
3. **นวัตกรรมการจัดการเรียนรู้:** ชุดแบบฝึกทักษะ 4 เรื่องย่อย ร่วมกับ กระบวนการเรียนรู้แบบร่วมมือ เทคนิค STAD 5 ขั้นตอน
4. **กลุ่มเป้าหมายในการพัฒนา:** นักเรียนชั้น ม.2/6 (40 คน) และ ม.2/7 (40 คน) รวม 80 คน
5. **ตารางแจกแจงความถี่คะแนนสอบเก็บคะแนน:** ตารางแจกแจงคะแนน 0–5 พร้อมสรุปผลสัมฤทธิ์และการสอนซ่อมเสริม
6. **ผลลัพธ์เชิงคุณภาพ 3 ด้าน:** มโนทัศน์ถูกต้อง, ทักษะทำงานเป็นทีม, ต่อยอด ม.ปลาย พร้อมคำขวัญ “เรียนดี มีวินัย ใฝ่คุณธรรม”
